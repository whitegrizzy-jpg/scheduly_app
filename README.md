# Scheduly — 할 일 앱 (주제 #2109 MP1: 할 일 앱 화면)

Flutter로 만든 할 일 관리 앱입니다. MP1에서는 **목록 + 입력 + 상태 변화**(할 일 추가, 완료 토글, 빈 상태 안내)를 구현했습니다.
저장은 MP2에서 붙이므로, MP1에서는 앱을 다시 시작하면 시험 데이터로 초기화됩니다.

## 실행 절차

- 프레임워크/SDK: **Flutter 3.47.5 (stable) / Dart 3.13.4**
- 실행 기기: Android 에뮬레이터 **Pixel_8 (Android API 37, 1080×2400)**
- 잠금 파일: `pubspec.lock`, `android/gradle/wrapper/gradle-wrapper.properties`

제출 ZIP에서는 Flutter 프로젝트가 `app/` 폴더에 있으므로 먼저 `cd app` 한 뒤 실행합니다.

```bash
flutter --version          # Flutter 3.47.5 / Dart 3.13.4 확인
flutter pub get
flutter emulators --launch Pixel_8
flutter run
```

테스트 실행:

```bash
flutter test
```

앱이 켜지면 로그인 화면에서 **「로그인 없이 둘러보기」**를 누르거나, 아무 아이디·비밀번호를 입력하고 **로그인**을 누르면 홈(할 일 목록)으로 들어갑니다.
(MP1·MP2는 데모 모드입니다. 계정 정보는 소스에 두지 않으며, 실제 인증은 MP3에서 BaaS로 연결합니다.)

## 구현 기능 목록

| 기능 | 설명 | 위치 |
|---|---|---|
| 할 일 목록 | 미완료 → 완료됨 순서로 카드 표시, 우선순위 배지(긴급/보통/여유), 상단 통계(남은 할 일·오늘 마감·완료) | `lib/screens/home_screen.dart` |
| 할 일 추가 | `+` 버튼 → 입력창 → **추가** 버튼(또는 키보드 완료)으로 목록 맨 위에 추가 | `_addTodo()` |
| 입력 검증 | 빈 값·공백만 입력하면 추가하지 않고 "할 일을 입력해주세요" 안내 | `_addTodo()` |
| 완료 토글 | 카드를 탭하면 완료/미완료가 즉시 바뀌고 체크·취소선·흐림 표시, 통계 숫자도 바로 갱신 | `_toggleTodo()` |
| 삭제 | 카드를 왼쪽으로 밀면 삭제, 스낵바의 **되돌리기**로 복구 | `_deleteTodo()` |
| 빈 상태 안내 | 할 일이 0개면 "등록된 할 일이 없습니다" 안내와 **할 일 추가하기** 버튼 표시 | `_EmptyTodoState` |
| 하단 탭 | 홈 / 캘린더 / 단체 / 손글씨 화면 전환 (캘린더·단체·손글씨는 화면 UI 시안) | `lib/components/bottom_nav.dart` |
| 프로필·로그아웃 | 홈 우측 상단 아바타 → 프로필 → 로그아웃 시 로그인 화면으로 복귀 | `ProfileScreen` |

## 화면 구성

| 화면 | 파일 | 내용 |
|---|---|---|
| 로그인 | `lib/screens/login_screen.dart` | 데모 로그인, 회원가입·비밀번호 찾기 화면 시안 |
| 홈(할 일) | `lib/screens/home_screen.dart` | 인사말·통계, 할 일 목록/추가/완료/삭제, 빈 상태, 메모 |
| 캘린더 | `lib/screens/calendar_screen.dart` | 월간 캘린더 시안 |
| 단체 | `lib/screens/group_schedule_screen.dart` | 단체 일정·참석 응답 시안 |
| 손글씨 | `lib/screens/handwriting_screen.dart` | 메모 인식 화면 시안 (MP4에서 ML Kit OCR로 교체 예정) |

상태 관리는 `StatefulWidget` + `setState`로 했습니다. 데이터 모델은 `lib/models/todo.dart`, 시험 데이터는 `lib/data/sample_todos.dart`에 있습니다.

## 확인 방법

### 할 일 목록

- 조작: 앱을 실행하고 로그인 화면에서 「로그인 없이 둘러보기」를 누른다
- 기대 결과: 홈 화면에 시험 데이터 할 일 4개가 미완료 3개, 완료됨 1개로 나뉘어 보인다
- 스크린샷: 01_login.png, 02_list.png

### 할 일 추가

- 조작: 「📋 할 일」 옆 `+` 버튼을 누르고 "Submit MP1 report"를 입력한 뒤 **추가**를 누른다
- 기대 결과: 입력한 할 일이 목록 맨 위에 미완료(기한 없음)로 추가되고 「남은 할 일」 숫자가 1 늘어난다
- 스크린샷: 03_add_input.png, 04_added.png

### 공백 입력 검증

- 조작: 입력창을 비우거나 공백만 넣고 **추가**를 누른다
- 기대 결과: 항목이 추가되지 않고 입력창 아래에 "할 일을 입력해주세요" 안내가 보인다
- 스크린샷: 05_empty_input.png

### 완료 토글

- 조작: 미완료 카드 「캡스톤 설계 보고서 제출」과 「Submit MP1 report」를 탭한다
- 기대 결과: 두 항목이 체크·취소선과 함께 「완료됨」으로 옮겨지고 통계가 남은 할 일 2 / 오늘 마감 0 / 완료 3으로 바뀐다. 완료된 카드를 다시 탭하면 미완료로 돌아온다
- 스크린샷: 06_toggled.png

### 빈 상태 안내

- 조작: 할 일 카드를 하나씩 왼쪽으로 밀어 모두 삭제한다
- 기대 결과: 미완료가 모두 사라지면 "남은 할 일이 없어요" 문구가, 전부 삭제하면 "등록된 할 일이 없습니다" 안내와 「할 일 추가하기」 버튼이 보이고 통계는 모두 0이 된다. 버튼을 누르면 입력창이 열린다
- 스크린샷: 07_empty_state.png

시험 데이터: lib/data/sample_todos.dart (더미 할 일 4개, 실제 개인정보 없음)

네트워크: 불필요 (오프라인/비행기 모드에서도 동작)
